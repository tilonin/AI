# Аудит управления и интерфейса AETHER

Дата проверки: 17 ноября 2026. Изменён существующий проект; исходная 3D-песочница сохранена.

## Проверенный референс

Открыты https://davia.ai и публичная страница Modern World: https://davia.ai/stories/20a21464-5d6f-497a-82a1-f3e0db540131 . Проверены каталог, страница игры, вкладки, карта/персонажи в описании и запуск Solo game. Сайт вернул сообщение **This game isn’t available on this device. To play, open Davia on a recent computer.** Внутриигровой интерфейс проверить не удалось. Поэтому реализация не объявляется точной копией Davia. Полноэкранная карта и плавающие панели реализованы по требованиям пользователя; неподтверждённые детали Davia не приписываются оригиналу. Ресурсы, логотип и персонажи Davia не использованы.

## Найденные ошибки и исправления

| Ошибка | Причина | Исправление и проверка |
|---|---|---|
| Панорамирование зависело от размера экрана | Пиксели мыши напрямую добавлялись к SVG-координатам | getScreenCTM().inverse() переводит координаты в viewBox; проверены pan/zoom |
| Колесо одновременно прокручивало страницу | Отсутствовал обработчик non-passive | Локальный wheel listener с preventDefault; интерфейс теперь занимает viewport |
| Масштабирование уходило от курсора | Масштаб менялся только вокруг центра | zoomAt сохраняет точку под курсором, предел 1–12× |
| Карту можно было потерять за экраном | Не было ограничений смещения | clampCamera ограничивает панораму по zoom |
| Перетаскивание выбирало страну | Click не отличался от drag | Порог 5 px и подавление click после drag, pointercancel/release capture |
| Камера двигалась рывками | Мгновенная смена transform | Независимые target/current и интерполяция через requestAnimationFrame |
| Геометрия заново собиралась при каждом движении | Построение строк path внутри render | Геометрия мемоизирована, обновляется только камера |
| Страна терялась после reload | selected не сохранялся | Сохраняется код выбранной страны, есть поиск и фокус камеры |
| Ошибка плана могла обрушить React | EventProcessor вызывался в updater setState | План рассчитывается до commit; исключения обрабатываются, состояние атомарно |
| Результат мог примениться к другому миру | Запрос не был связан со снимком | Проверяется ссылка на исходный world; load/import отменяют активный запрос |
| Повторное действие | Не было idempotency ключа | commandId проверяется движком и сохраняется; немедленный ref-guard блокирует повторную отправку |
| Отмена снова отправляла команду | React переиспользовал кнопку cancel как submit до native default action | Разные key кнопок, preventDefault, сначала инвалидируется запрос; Playwright проверяет один запрос и ноль применений |
| Текст без эффекта объявлялся успехом | Принимался пустой план | Нулевые воздействия пропускаются, неприменимый план отклоняется |
| Некорректный импорт ломал UI | Проверялись только массивы и конечность чисел | Полный Zod-контракт мира, уникальность стран, ссылки потоков и модификаторов |
| Пропадало сохранение при недоступном localStorage | Ошибки хранилища не сообщались или блокировали команду | Необязательная история не блокирует исполнение, ошибка автосохранения сообщается; экспорт доступен |
| Возможны NaN при нулевом ВВП | Деление на GDP без нижней границы | Защищён знаменатель, ВВП положительный, рост ограничен; проверены 10 лет симуляции |
| На карте не отражался новый контролёр | Геометрия всегда окрашивалась по исходной стране | territories — часть WorldState, политическая карта окрашивается по текущему владельцу |
| Сбой Google Fonts засорял консоль | Внешний @import был обязательным запросом | Удалён сетевой импорт, используются системные fallback-шрифты |

## Интерфейс

Центральная SVG-карта на весь экран. Верхняя компактная навигация и поиск. Слева инструменты наблюдения, снизу ввод длинной свободной команды. Справа одна сворачиваемая панель: государство, новости, история запросов или настройки. Политическая/географическая/карта показателей. Поиск с Enter и плавным фокусом. Клик, keyboard Enter/Space и контекстное меню по стране. Флаги Unicode; лидер и политическая система задаются для условного сценария, реальные действующие лидеры не выдумываются.

Лента содержит только записи применённых событий/автономных решений, фильтры страны/категории, дату, переход к месту и отчёт before/after. Пустой план не создаёт новости. Отложенные процессы явно отделены от немедленных изменений. Автономная адаптация энергоснабжения проверяется каждые 30 игровых дней: при низком снабжении запускается процесс без дублирования активной диверсификации. Эти автономные решения эвристические; свободный ввод интерпретируется подключённой LLM.

Горячие клавиши: `/` — команда, `F` — поиск, пробел — время, `H` — интерфейс, Esc — закрыть. Карта: стрелки, +/−, Home. Ctrl/Cmd+Enter отправляет запрос. Отчёт удерживает Tab внутри диалога и возвращает фокус после закрытия.

## Проверки

- 22 unit/integration проверки: схемы, математика камеры, торговый баланс, бюджет, идемпотентность, атомарность, владение территориями, сохранения, длительная симуляция и прежняя физика.
- 10 Playwright-сценариев в `tests/atlas.spec.ts`: загрузка и выбор, поиск, reload, pan/zoom/keyboard, слои и context menu, скрытие UI, корректный AI-план с изменением показателей/реакциями/новостями, отмена, неверный план, недоступный AI, история запросов, save/load/rollback, территориальный контроль, мобильная компоновка и консоль.
- Ответы AI в E2E — явно тестовые route fixtures, они проверяют реальную клиентскую цепочку, а не качество платного провайдера. Настоящий LLM-провайдер без пользовательского ключа не тестировался.
- Chromium Headless Shell из официального Playwright. Полный Chrome в этой среде не запускается из-за недоступного process singleton socket; Headless Shell поддерживается и выполняет тесты.
- TypeScript strict и production-сборка.

## Честные границы

Нет заявления о полном совпадении интерфейса Davia. 3D-лаборатория — отдельная сохранённая песочница; 3D-глобус не добавлен и не подменяется этой кнопкой. Передача контроля работает для целых существующих географических территорий; редактирование полигонов, новые границы и внутрирегиональные фронты не реализованы. Нет автономных LLM-вызовов для каждого реального лидера, боевых подразделений или инфраструктурной модели. Числа сценария и торговая сеть по-прежнему синтетические. PostgreSQL API обслуживает прежние 3D-снимки; геополитический режим сохраняется локально и через JSON. Настройки модели и доступ к API остаются необходимыми для свободных команд.
