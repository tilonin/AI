# Реализованные механики

| Система | Реальное поведение |
|---|---|
| Физические объекты | Блоки, сферы, кристаллы и роботы имеют массу, коллайдеры, трение и скорости |
| Манипуляции | Создание в указанной точке, выбор, drag, телепортация по осям, импульс, дублирование, удаление |
| Разрушение | Сильные столкновения уменьшают прочность блока; при исчерпании появляются 3 физических осколка-кристалла |
| Агент | Исследует остров, выбирает ближайший кристалл, переносит энергию к маяку, обходит соседние объекты |
| Задание | Доставить 5 кристаллов; прогресс записывается в сохранение |
| Время | Пауза, 0.5× / 1× / 2×; фиксированный шаг физики сохраняется |
| Окружение | Гравитация 0–25, день / закат / ночь, свет центрального маяка |
| Частицы | Процедурные световые пылинки запасного рендера; снижаются при большом количестве объектов |
| AI-команды | Прямо меняют мир, проходят структурированную валидацию и записываются в журнал |
| Сохранения | Ручные и автоматический слоты, JSON импорт/экспорт, дополнительный PostgreSQL API |
| Защита мира | Не более 120 объектов; выходящие за пределы мира тела возвращаются на остров |

Кристаллы при сборе превращаются в переносимую агентом энергию. Они не закрепляются физическим joint к агенту. Игра не реализует произвольное строительство ландшафта, сложную деформацию мешей, полноценный pathfinding или сетевой мультиплеер.
